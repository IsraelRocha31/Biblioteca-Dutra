17. ENDPOINTS ATUAIS
--------------------------------------------------------------------------------
API base atual:
  /api

Sistema:
  GET  /api
  GET  /api/health

Autenticação:
  POST /api/auth/login
  POST /api/auth/criar-admin   (JWT + super admin)
  GET  /api/auth/perfil        (JWT)

Livros:
  GET    /api/livros
  GET    /api/livros/isbn/:isbn
  GET    /api/livros/:id/capa
  GET    /api/livros/:id
  POST   /api/livros           (JWT + super admin)
  PUT    /api/livros/:id       (JWT + super admin)
  DELETE /api/livros/:id       (JWT + super admin)

GET /api/livros suporta:
  busca
  autor
  page
  limit

A busca textual consulta nome, ISBN, autor e descrição com ILIKE.

19. VARIÁVEIS DE AMBIENTE
--------------------------------------------------------------------------------
O /.env atual contém 45 variáveis.

Grupos:
  - Vercel/Supabase;
  - identidade/rotas;
  - administrador/autenticação;
  - frontend/desenvolvimento;
  - backend/HTTP;
  - PostgreSQL;
  - livros/upload/paginação.

A conexão runtime usa POSTGRES_URL.

Configuração pública do frontend é validada em frontend/vite.config.ts e
injetada em __APP_CONFIG__.

Configuração do backend é acessada somente por backend/src/config/env.js.

Existe somente um arquivo de ambiente no projeto: /.env.
O comando npm run env:check valida 45 variáveis e rejeita qualquer .env* extra.
